# technology/

Технологии и исследования (Итерация 11).

- `technology.gd` тип технологии: цена в науке, требования, эффект
- `technology_catalog.gd` загрузка `data/technologies/technologies.json`, проверка графа требований
- `technology_model.gd` формулы: бонусы страны, доступные технологии, прогресс
- `research_rules.gd` кто что может исследовать
- `research_system.gd` `ResearchSystem` (фаза WORLD_UPDATE, после ECONOMY)

Правила MVP: одна текущая технология на страну; без выбора наука пропадает;
остаток после завершения пропадает; эффект работает со следующего сезона;
смена исследования сбрасывает прогресс. AI пока не выбирает исследования (Итерация 16).
Выбор идёт командой `StartResearchCommand`.
