# WORLD EMPIRES

Глобальная пошаговая стратегия (1 ход = 1 сезон). Godot 4.7, GDScript, PC.
Сейчас: вертикальный срез MVP. Готовы итерации 0–10 из `MVP Implementation Roadmap`.

## Запуск

1. Открыть проект в Godot 4.7 (`project.godot`), F5.
2. Выбрать страну справа, нажать `Start`.
3. Управление: ЛКМ выбрать регион; колесо зум; ПКМ/СКМ тянуть, WASD/стрелки сдвиг; F1 скрыть debug-панель.
4. Клик по региону с белым квадратом открывает панель города: там можно заказать здания.
5. `Next Season` проводит один сезон.

## Тесты

    GODOT=путь/к/godot ./tests/run_all.sh        # Windows (Git Bash): GODOT="C:\...\Godot.exe"

Нужен вывод `ALL TESTS PASSED`. Скрипт сам ловит тесты, которые не скомпилировались
(Godot в этом случае выходит с кодом 0).

## Что где лежит

| Папка | Содержимое |
|---|---|
| `core/` | время и порядок тика, EventBus, RNG, ID, команды, сохранения |
| `world/` | WorldState, карта, регионы, страны, города, население |
| `economy/` | ресурсы, бюджет, здания и строительство |
| `ui/` | debug-HUD, выбор страны, панели экономики и города |
| `data/` | карта, страны, города, здания (JSON) |
| `tools/map_generator/` | Python-генераторы карты, стран и городов |
| `tests/` | юнит-тесты и `run_all.sh` |
| `technology/ military/ diplomacy/ ai/` | пока пусто (итерации 11–16) |

## Правила архитектуры

- **WorldState** единственный источник правды. UI и AI только читают его.
- **Любое изменение мира идёт через `CommandBus`** (`Command.validate` затем `execute`). Игрок и AI одним путём.
- **Системы** (`IGameSystem`) подключаются в `core/game_systems.gd` и работают по фазам `TickOrder`.
  Порядок фаз зафиксирован тестом.
- **Системы не знают друг о друге**: связь через сигналы `WorldState` и события `EventBus`.
- **Данные в JSON**, баланс в `*_config.gd`.
- **Сохраняется только динамическое состояние.** Геометрия карты загружается из `data/`.
  Производные индексы (`Country.regions`, `Region.cities`) не сохраняются, а пересобираются.
- **Дробные числа в сохранении**: JSON в Godot хранит ~15 значащих цифр, поэтому всё, что
  сохраняется, должно быть квантовано (деньги: `EconomyModel.round_money`, до копеек).
- **Отступы только табами.**
